# Clockoli

**Free, open-source time tracking that lives in your GitHub repo.**

We've been building open-source software on GitHub for years. We use it for code, documentation, and project management. The one thing we were missing was time tracking. So we built Clockoli.

Clockoli is a browser extension for individuals and teams. Track time on GitHub issues, pull requests, or any website. Keep personal work in your own private repository and track time together with your team in a shared one.

**Free forever. No per-seat fees. No usage limits imposed by Clockoli. No separate server to run.**

## What makes Clockoli different?

- **Your data is yours.** Time entries are stored as readable JSON Lines files in private GitHub repositories you control.
- **GitHub is the backend.** No separate Clockoli account, database, or application server.
- **Track time wherever you work.** Start a timer directly on a GitHub issue or pull request, or use the extension on any website.
- **Built for teams.** Share time records, edit them in a timeline or calendar, and generate reports across teammates and projects.
- **Reports and invoicing.** Export timesheets, calculate billable amounts, and create PDF invoices. Hourly rates stay in your browser.
- **Ready for AI agents.** Clone your time repository and let an AI agent analyze your work directly. No special API or export needed.
- **Open source.** Inspect the code, contribute, or fork it and keep using it independently of us.
